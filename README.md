# Digiplus Grand Indonesia – Store Dashboard (QF01)
1. Google Cloud: aktifkan Sheets API, buat service account, unduh key JSON.
2. Share Google Sheet ke email service account (akses Viewer).
3. Vercel > Settings > Environment Variables: isi semua variabel di .env.example.
4. Push ke GitHub; Vercel build otomatis. Lokal: npm i && npm run dev.
